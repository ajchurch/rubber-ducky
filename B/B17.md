# B17. Implement one of the current state-of-the-art solutions and evaluate it.

With the help of Anthropic's Claude, I created a demo Agentic SOC triage agent. Basically, it uses an LLM as a Tier-1 analyst that takes in the high volume, repetitive alert triage load so the 'human analysts' can focus on the alerts that actually matter.

1) The system made consists of A labeled dataset of 100 synthetic security alerts (60 malicious, 40 benign) which covers six MITRE ATT&CK techniques: credential dumping (T1003), process injection (T1055), command-and-control (T1071), valid-account abuse (T1078), exploitation of public-facing apps (T1190), and ransomware (T1486).

2) A Python script that sends each alert to Llama 3.3 70B (via [Groq](https://groq.com/)'s free API) with a structured prompt asking for a JSON verdict on whether is it malicious, what MITRE technique, what attack stage, what action to take, and a one sentence rationale. It handles JSON parsing failures, applies fail-safe defaults, and records per-alert latency.

3) An evaluation method that scores the agent against the ground-truth labels using precision, recall, F1, MITRE classification accuracy, latency distribution, action distribution, and per-technique recall.

The results of the agent were as follows:
Precision  1.00
Recall  0.97
F1  0.98
MITRE technique accuracy (on true positives)  0.60
Mean latency  0.52s
Auto-close rate  41%

The agent did well at deciding whether the alert was malicious with a 98% accuracy with no false positives. However, this is probably easier than it looks, because my dataset is cleaner than real SOC traffic.

The more honest result is the MITRE score as the agent correctly named the attack technique only 60% of the time, so it knew something was wrong almost always, but didn't always know why.

One alert (A024, a C2 beacon) was auto-closed by mistake, with the agent calling it a 'regular automated process', This is the exact failure an agentic SOC has to avoid in production, and it shows why low-confidence verdicts should never auto-close.

On the positive side, the agent's confidence scores were reliable when high, every alert it was >85% confident about was correct, which means a real deployment could safely auto-close high-confidence cases and send the rest to a human.

Limitations wise, the dataset was synthetic and labeled by Claude, only one simple model was tested, and I didn't try adversarial cases. This probably wouldn't be something to actually use in real life, but it was nice little demo to see how it all worked.

**The Triage Agent Code**
```bash
from __future__ import annotations

import argparse
import csv
import json
import logging
import os
import re
import sys
import time
from pathlib import Path

from dotenv import load_dotenv

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s",
    datefmt="%H:%M:%S",
)
log = logging.getLogger("triage_agent")

# Quiet the noisy per-request INFO logs from the SDK / HTTP layer.
for _noisy in ("httpx", "groq", "groq._base_client"):
    logging.getLogger(_noisy).setLevel(logging.WARNING)

PROJECT_ROOT = Path(__file__).resolve().parents[1]
ALERTS_CSV = PROJECT_ROOT / "data" / "alerts.csv"
RESULTS_CSV = PROJECT_ROOT / "results" / "triage_results.csv"

DEFAULT_MODEL = "llama-3.3-70b-versatile"
DEFAULT_RPM = 30  # Groq free tier is generous; pace anyway to be safe
MAX_TOKENS = 1024
MAX_RETRIES = 5

VALID_ACTIONS = {"auto_close", "analyst_review", "escalate", "contain_host"}
VALID_STAGES = {
    "reconnaissance", "initial_access", "execution", "persistence",
    "privilege_escalation", "defense_evasion", "credential_access",
    "discovery", "lateral_movement", "collection", "c2", "exfiltration",
    "impact", "benign",
}

SYSTEM_PROMPT = "You are a Tier-1 SOC analyst. Triage the following security alert."

USER_PROMPT_TEMPLATE = """You are a Tier-1 SOC analyst. Triage the following security alert.

Alert:
{raw_log}
Source host: {source_host}
Timestamp: {timestamp}

Respond ONLY with a JSON object (no prose, no markdown fences):
{{
  "is_malicious": true | false,
  "confidence": 0.0-1.0,
  "mitre_technique": "T-number or 'benign'",
  "attack_stage": "reconnaissance | initial_access | execution | persistence | privilege_escalation | defense_evasion | credential_access | discovery | lateral_movement | collection | c2 | exfiltration | impact | benign",
  "recommended_action": "auto_close | analyst_review | escalate | contain_host",
  "reasoning": "one-sentence explanation"
}}"""


def parse_args() -> argparse.Namespace:
    p = argparse.ArgumentParser(description="Triage SOC alerts with an LLM on Groq.")
    p.add_argument("--limit", type=int, default=None,
                   help="Only triage the first N alerts (useful for a smoke test).")
    p.add_argument("--model", default=DEFAULT_MODEL,
                   help=f"Groq model to use (default: {DEFAULT_MODEL}).")
    p.add_argument("--rpm", type=float, default=DEFAULT_RPM,
                   help=f"Max requests/minute to respect the free-tier quota "
                        f"(default: {DEFAULT_RPM}).")
    p.add_argument("--resume", action="store_true",
                   help="Skip alerts already triaged in results/triage_results.csv "
                        "and re-run the rest (useful after an interruption).")
    return p.parse_args()


def load_alerts() -> list[dict]:
    if not ALERTS_CSV.exists():
        log.error("Alert dataset not found at %s. Run generate_dataset.py first.", ALERTS_CSV)
        sys.exit(1)
    with ALERTS_CSV.open(newline="", encoding="utf-8") as f:
        rows = list(csv.DictReader(f))
    log.info("Loaded %d alerts from %s", len(rows), ALERTS_CSV)
    return rows


def load_completed_rows() -> dict[str, dict]:
    """Rows already triaged with a real verdict (not PARSE_ERROR), keyed by alert_id."""
    if not RESULTS_CSV.exists():
        return {}
    rows = {}
    with RESULTS_CSV.open(newline="", encoding="utf-8") as f:
        for r in csv.DictReader(f):
            if str(r.get("predicted_malicious")) in {"0", "1"}:
                rows[r["alert_id"]] = r
    return rows


def extract_json(text: str) -> str:
    """Pull a JSON object out of a model response.

    Handles markdown code fences and any stray prose around the object by
    grabbing the substring between the first '{' and the last '}'.
    """
    cleaned = (text or "").strip()
    fence = re.match(r"^```(?:json)?\s*(.*?)\s*```$", cleaned, re.DOTALL)
    if fence:
        cleaned = fence.group(1).strip()
    start = cleaned.find("{")
    end = cleaned.rfind("}")
    if start != -1 and end != -1 and end > start:
        return cleaned[start:end + 1]
    return cleaned


def normalize_verdict(data: dict) -> dict:
    """Coerce a parsed verdict into the columns we record, with safe fallbacks."""
    is_mal = data.get("is_malicious")
    if isinstance(is_mal, str):
        is_mal = is_mal.strip().lower() in {"true", "1", "yes"}
    predicted_malicious = 1 if bool(is_mal) else 0

    try:
        confidence = float(data.get("confidence"))
    except (TypeError, ValueError):
        confidence = ""
    if confidence != "":
        confidence = max(0.0, min(1.0, confidence))

    technique = str(data.get("mitre_technique", "")).strip()
    if technique.lower() in {"benign", "none", "n/a", ""}:
        technique = "benign" if predicted_malicious == 0 else technique

    action = str(data.get("recommended_action", "")).strip()
    if action not in VALID_ACTIONS:
        action = "analyst_review"  # safe default: send to a human

    reasoning = str(data.get("reasoning", "")).strip()

    return {
        "predicted_malicious": predicted_malicious,
        "predicted_technique": technique,
        "confidence": confidence,
        "action": action,
        "reasoning": reasoning,
    }


def make_caller(api_key: str, model: str):
    """Return a function call(system_prompt, user_prompt) -> raw_text."""
    try:
        from groq import Groq
    except ImportError:
        log.error("groq not installed. Run: pip install -r requirements.txt")
        sys.exit(1)

    client = Groq(api_key=api_key)

    def call(system_prompt: str, user_prompt: str) -> str:
        resp = client.chat.completions.create(
            model=model,
            messages=[
                {"role": "system", "content": system_prompt},
                {"role": "user", "content": user_prompt},
            ],
            temperature=0,
            max_tokens=MAX_TOKENS,
            response_format={"type": "json_object"},
        )
        return resp.choices[0].message.content or ""

    return call


class RateLimiter:
    """Enforce a minimum interval between calls to respect a requests/min quota."""

    def __init__(self, rpm: float):
        self.min_interval = 60.0 / rpm if rpm and rpm > 0 else 0.0
        self._last = 0.0

    def wait(self) -> None:
        if self.min_interval <= 0:
            return
        elapsed = time.monotonic() - self._last
        if elapsed < self.min_interval:
            time.sleep(self.min_interval - elapsed)
        self._last = time.monotonic()


def backoff_seconds(exc: Exception, attempt: int) -> float:
    """How long to wait before a retry, honoring server-suggested delays."""
    s = str(exc)
    if "429" in s or "rate limit" in s.lower() or "RESOURCE_EXHAUSTED" in s:
        # Respect the server's suggested retry delay if the error includes one.
        m = (re.search(r"try again in ([0-9.]+)s", s)
             or re.search(r"retry in ([0-9.]+)s", s)
             or re.search(r"retryDelay'?:?\s*'?([0-9.]+)s", s))
        if m:
            return min(float(m.group(1)) + 1.0, 90.0)
        return 30.0
    return min(2 ** attempt, 30.0)  # transient (5xx etc.): exponential backoff


def triage_one(call, alert: dict, limiter: "RateLimiter") -> tuple[dict, float, bool]:
    """Triage a single alert. Returns (verdict_dict, latency_sec, parse_ok)."""
    user_prompt = USER_PROMPT_TEMPLATE.format(
        raw_log=alert["raw_log"],
        source_host=alert["source_host"],
        timestamp=alert["timestamp"],
    )

    last_err = None
    for attempt in range(1, MAX_RETRIES + 1):
        limiter.wait()
        start = time.perf_counter()
        try:
            raw_text = call(SYSTEM_PROMPT, user_prompt)
            latency = time.perf_counter() - start
        except Exception as e:  # noqa: BLE001 - network/API errors, retry
            last_err = e
            wait = backoff_seconds(e, attempt)
            log.warning("  API error on attempt %d/%d: %s (retrying in %.0fs)",
                        attempt, MAX_RETRIES, str(e).splitlines()[0][:120], wait)
            time.sleep(wait)
            continue

        try:
            data = json.loads(extract_json(raw_text))
            return normalize_verdict(data), latency, True
        except (json.JSONDecodeError, AttributeError, TypeError) as e:
            log.warning("  JSON parse failed (attempt %d/%d): %s | raw: %.120s",
                        attempt, MAX_RETRIES, e, (raw_text or "").replace("\n", " "))
            last_err = e
            continue

    log.error("  Giving up after %d attempts: %s", MAX_RETRIES, last_err)
    fallback = {
        "predicted_malicious": "",
        "predicted_technique": "PARSE_ERROR",
        "confidence": "",
        "action": "analyst_review",
        "reasoning": f"triage failed: {last_err}",
    }
    return fallback, 0.0, False


def resolve_api_key() -> str:
    key = os.environ.get("GROQ_API_KEY")
    if not key:
        log.error("GROQ_API_KEY not set. Copy .env.example to .env and add your key.")
        log.error("Get a free key at https://console.groq.com/keys")
        sys.exit(1)
    return key


def main() -> None:
    args = parse_args()
    load_dotenv(PROJECT_ROOT / ".env")

    api_key = resolve_api_key()
    call = make_caller(api_key, args.model)
    limiter = RateLimiter(args.rpm)
    log.info("Backend: groq | model: %s | rate limit: %.0f req/min", args.model, args.rpm)

    alerts = load_alerts()
    if args.limit:
        alerts = alerts[: args.limit]
        log.info("Limiting run to first %d alerts", len(alerts))

    RESULTS_CSV.parent.mkdir(parents=True, exist_ok=True)
    fieldnames = [
        "alert_id", "ground_truth_malicious", "ground_truth_technique",
        "predicted_malicious", "predicted_technique", "confidence",
        "action", "reasoning", "latency_sec",
    ]

    # Resume: carry over previously-good rows, re-run the rest. The file is
    # always rewritten fresh, so PARSE_ERROR rows from a prior run don't leave
    # duplicate alert_ids behind.
    completed = load_completed_rows() if args.resume else {}
    if args.resume and completed:
        before = len(alerts)
        alerts = [a for a in alerts if a["alert_id"] not in completed]
        log.info("Resume: %d already done, %d remaining (of %d).",
                 len(completed), len(alerts), before)

    if not alerts:
        log.info("Nothing to do — all alerts already triaged. Run: python src/evaluate.py")
        return

    if limiter.min_interval > 0:
        est_min = len(alerts) * limiter.min_interval / 60.0
        log.info("Pacing ~%.1fs between alerts -> ~%.1f min for %d alerts.",
                 limiter.min_interval, est_min, len(alerts))

    results = []
    n_parse_fail = 0
    t0 = time.perf_counter()

    with RESULTS_CSV.open("w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=fieldnames)
        writer.writeheader()
        for prior in completed.values():
            writer.writerow({k: prior.get(k, "") for k in fieldnames})
        f.flush()

        for i, alert in enumerate(alerts, start=1):
            verdict, latency, ok = triage_one(call, alert, limiter)
            if not ok:
                n_parse_fail += 1

            row = {
                "alert_id": alert["alert_id"],
                "ground_truth_malicious": alert["ground_truth_malicious"],
                "ground_truth_technique": alert["ground_truth_technique"],
                "predicted_malicious": verdict["predicted_malicious"],
                "predicted_technique": verdict["predicted_technique"],
                "confidence": verdict["confidence"],
                "action": verdict["action"],
                "reasoning": verdict["reasoning"],
                "latency_sec": round(latency, 3),
            }
            writer.writerow(row)
            f.flush()  # persist incrementally so a crash doesn't lose progress
            results.append(row)

            verdict_label = (
                "MALICIOUS" if verdict["predicted_malicious"] == 1
                else "benign" if verdict["predicted_malicious"] == 0
                else "ERROR"
            )
            log.info(
                "[%3d/%3d] %s -> pred=%-9s technique=%-12s action=%-14s %.2fs",
                i, len(alerts), alert["alert_id"], verdict_label,
                verdict["predicted_technique"], verdict["action"], latency,
            )

    elapsed = time.perf_counter() - t0
    log.info("=" * 60)
    log.info("Done. Triaged %d alerts this run in %.1fs (avg %.2fs/alert).",
             len(results), elapsed, elapsed / max(len(results), 1))
    if completed:
        log.info("Carried over %d previously-completed alerts.", len(completed))
    if n_parse_fail:
        log.warning("%d alert(s) failed to parse and were recorded as PARSE_ERROR. "
                    "Re-run with --resume to retry just those.", n_parse_fail)
    log.info("Results written to %s", RESULTS_CSV)
    log.info("Next: python src/evaluate.py")


if __name__ == "__main__":
    main()
```
