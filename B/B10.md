# B10. Participate in a cybersecurity activity as part of job/internship/volunteering etc.

As part of my job as a Salesforce Developer at Uniquely Cloud, I need to often undertake training to assist me in learning how to do things for upcoming projects with clients.

Salesforce have a program called '[Trailhead](https://trailhead.salesforce.com/today)'  which essentially is their platform to teach people skills on how to use their platform no matter what role you have in a company that uses Salesforce.

I undertook the [Event Monitoring](https://trailhead.salesforce.com/content/learn/modules/event_monitoring) module which essentially taught me how to enable event monitoring (a security and performance tool that tracks details about user activity and system operations within a Salesforce org) so the admins are able to see user activity (in case things go wrong and people start doing the wrong, which for some clients has been the case).
