# B24. Design and implement access control of your choice.

I built a small web app that protects an articles API using **Role-Based Access Control (RBAC)** with resource ownership. Different users get different permissions based on their role, and people can also manage things they own.

## The Model

I used four roles with these permissions:
admin had read write and delete priviliges
editor had read and write priviliges
viewer only had reaad priviliges
and owner had read write and delete priviliges ONLY on their own 'articles'

It worked using the following workflow:
1) A user sends a request to the Flask app.
2) The app asks OPA: 'Can this user do this action?'
3) OPA checks the policy rules and replies yes or no.
4) The app either does the action or returns Forbidden.

The key idea is that the rules live in a separate file, not in the app code. This makes them easier to change and audit.

I used the following tools with the help of Anthropic's Claude:
- **Python + Flask** — the web app
- **Open Policy Agent (OPA)** — the policy engine
- **Rego** — OPA's rule language
- **Docker** — runs OPA in a container

## The Rules (`policy.rego`)

```rego
package authz
import rego.v1

default allow := false

# Admins can do anything
allow if {
    input.user.role == "admin"
}

# Editors can read and write
allow if {
    input.user.role == "editor"
    input.action in ["read", "write"]
}

# Viewers can only read
allow if {
    input.user.role == "viewer"
    input.action == "read"
}

# Owners can do anything to their own stuff
allow if {
    input.user.id == input.resource.owner
}
```

## The App (`app.py`)

The important part is this function, every protected route calls it:

```python
def check_access(user, action, resource=None):
    payload = {"input": {"user": user, "action": action, "resource": resource or {}}}
    response = requests.post(OPA_URL, json=payload)
    return response.json().get("result", False)
```

And here's how a route uses it:

```python
@app.route("/articles/<aid>", methods=["DELETE"])
def delete_article(aid):
    user = get_user()
    article = articles.get(aid)
    if not check_access(user, "delete", article):
        return jsonify({"error": "Forbidden"}), 403
    del articles[aid]
    return jsonify({"deleted": aid})
```

## Running It

```bash
# Start OPA
docker run -d --name opa -p 8181:8181 \
  -v "$(pwd)/policy.rego:/policy.rego" \
  openpolicyagent/opa:latest \
  run --server --addr 0.0.0.0:8181 /policy.rego

# Start the app
python3 app.py
```

## Testing

I tested each role with curl:

| Test | User  | Action | Expected | Result |

| 1    | alice (admin)  | delete | allow  | ✓ 200 |
| 2    | carol (viewer) | delete | block  | ✓ 403 |
| 3    | carol (viewer) | read   | allow  | ✓ 200 |
| 4    | bob (editor)   | update | allow  | ✓ 200 |
| 5    | dave (owner)   | update own item | allow | ✓ 200 |

Example commands:

```bash
# Admin deletes — works
curl -X DELETE -H "X-User: alice" http://localhost:5001/articles/1

# Viewer tries to delete — blocked
curl -X DELETE -H "X-User: carol" http://localhost:5001/articles/2
```
