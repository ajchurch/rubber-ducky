# B30. Generate an AI-created image, applying an imperceptible watermark on it and then perform an image-to-image regeneration or editing process to make sure the watermark is detectable---the watermark survives.
[Link to my chat with Gemini](https://gemini.google.com/share/16c2ba9b93c6)

Using Google Gemini, I crated an initial image of a "super cool rubber ducky in the wild west during sunset." This automatically applied a SynthID watermark (Google's AI image 'detector') directly into the pixel data of the file. I then performed an image-to-image edit to change the sunset to a pink-orange sunest and the bandana to blue, specifically testing if this metadata and pixel-level signal would remain intact. The SynthID watermark survived this regeneration process because it is designed to be a robust steganographic signature that persists even after significant visual modifications like re-colouring. Even though the pixels were altered to change parts of the image, the underlying digital provenance remained detectable by Google's verification tools.
